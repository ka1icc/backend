# Задание #103 — Тестовое задание Сбербанк

**Сложность:** легко

## Формулировка

Вывести список имён сотрудников, получающих большую заработную плату, чем у непосредственного руководителя.

## Результирующая таблица

| Поле  | Описание        |
|-------|-----------------|
| `name` | Имя сотрудника |

## Данные

- База данных и скрипты схемы/данных лежат в директории **`tests`** под номером задания (**103**).
- Таблица **`employees`**: `id`, `department_id`, `chief_id`, `name`, `salary`.
  - `chief_id` — идентификатор непосредственного руководителя (ссылка на `employees.id`), может быть `NULL` у руководителей верхнего уровня.

## Решение

Используется самосоединение таблицы `employees`: сотрудник соединяется со своим руководителем по `chief_id = chief.id`, в результат попадают только те, у кого `salary` больше, чем у руководителя.

Файл решения: **`tests/103/solution.sql`**

## Запуск

1. Поднять БД и выполнить скрипты из `tests/` (например, `employees.sql`, `departments.sql`).
2. Выполнить запрос из `tests/103/solution.sql`.

Пример формата ответа:

|   | name              |
|---|--------------------|
| 1 | ...                |
| 2 | ...                |

Конкретные имена зависят от загруженных данных.
