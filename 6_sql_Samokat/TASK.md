# Задание проекта: Самокат #97

## Описание

**Источник:** тестовое задание Самокат  
**Номер задания:** 97  
**Сложность:** средняя  

## Формулировка

Посчитать количество **работающих складов на текущую дату** по каждому городу. Вывести только те города, у которых количество складов **более 80**.

## Выходные данные

Результирующая таблица с полями:

| Поле             | Описание                |
|------------------|-------------------------|
| `city`           | Город                   |
| `warehouse_count`| Количество складов      |

## Условие «работающий склад»

Склад считается работающим на текущую дату, если:

- дата открытия не позже текущей даты: `date_open <= CURRENT_DATE`;
- склад не закрыт на текущую дату: `date_close IS NULL` или `date_close > CURRENT_DATE`.

## Данные и схема

- Описание задания: `tests/97.md`
- Схема и данные: таблица `warehouses` в `tests/warehouses.sql`  
  Поля: `warehouse_id`, `name`, `city`, `date_open`, `date_close`.

## Решение

Файл с запросом: **`tests/97_solution.sql`**

Запрос:

1. Фильтрует склады по условию «работает на текущую дату».
2. Группирует по `city`.
3. Считает количество складов и оставляет только города с `warehouse_count > 80`.
4. Сортирует по убыванию количества складов.

## Как запустить

1. Поднять БД (например, SQLite/PostgreSQL) и выполнить `tests/warehouses.sql` для создания таблицы и вставки данных.
2. Выполнить запрос из `tests/97_solution.sql` в этой же БД.

Пример для SQLite из корня проекта:

```bash
sqlite3 tests/warehouses.db < tests/warehouses.sql
sqlite3 tests/warehouses.db < tests/97_solution.sql
```

(Предварительно создать БД и при необходимости скорректировать синтаксис под вашу СУБД.)
